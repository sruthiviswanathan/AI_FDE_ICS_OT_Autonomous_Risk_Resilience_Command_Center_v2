# Baseline KPI Catalogue

Measure before and after intervention:
- asset inventory disagreement rate
- unknown/unowned asset rate
- telemetry bad/uncertain quality rate
- stale configuration rate
- mean time to contextualize an OT alert
- alerts per actionable incident
- safety-bypass aging
- vulnerability-to-process-impact coverage
- remote-session approval compliance
- restore-test freshness
- recovery runbook completeness
- time to establish cyber-physical incident confidence
- time to safe containment recommendation
- degraded-operation duration
- false-positive escalation rate
- decision evidence completeness
- human approval latency for consequential actions
- AI cost per analyzed incident / avoided escalation
